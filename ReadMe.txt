
Sayın Murat Yücedağ hocamızın Udemy platformunda bizlere sunduğu ve toplamda iki bölümden oluşan MyPortfolio Projesini tamamladığımı duyurmaktan mutluluk duyuyorum! Bu proje Code-First yaklaşımını temel alarak ve ASP.NET Core 8.0 sürümü ile geliştirilmiştir. Proje iki ana bölümden oluşmaktadır:

Ana Sayfa
Admin Paneli
🛠️ Proje Özellikleri
Admin Panelinde CRUD İşlemleri: Veritabanı ile entegre bir şekilde Ekleme, Güncelleme ve Silme işlemleri yapılmaktadır.
Veritabanı Entegrasyonu: Projede yer alan veriler veritabanından çekilmektedir.
🚀 Kullanılan Teknolojiler
Backend
C#: Backend tarafında kullanılan temel yazılım dili.
Microsoft SQL Server: Veritabanı yönetim sistemi.
Code-First Yaklaşımı: Veritabanı tasarımı Entity Framework Core ile kodlama aşamasında oluşturulmuştur.
Frontend
HTML: Sayfa yapılandırmaları için kullanılmıştır.
CSS: Sayfa stillerinin belirlenmesi için tercih edilmiştir.
Bootstrap: Hızlı ve modern bir kullanıcı arayüzü oluşturmak için kullanılmıştır.
🔧 Proje Yapısı
Controller: CRUD işlemleri için controller sınıfları bulunmaktadır.
DTOs (Data Transfer Objects): Verilerin belirli bileşenlerle paylaşıldığı DTO sınıfları kullanılmaktadır.
📦 Kullanılan Framework Sürümü
Entity Framework Core 8.0
